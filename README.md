# 展务导览、通行与志愿者公告

本地站点模拟展馆和馆外接续工坊，所有终端、活动、路线和服务点均为合成。终端连接、班前发布单、现场通行及志愿者公告台从页面导航进入。现场人员用“现场演练轮次”向前推进轮次。关闭浏览器不会复位后端会话或公告。整个服务重启后从第 1 轮开始。

## 终端页面

终端连接提供可检查时窗及终端、入口、语言与操作方式的选择。时窗含起始轮，不含结束轮。同一终端在一个时刻可开一个检查会话。检查中需要按页面从首页进入。相同地址的内容依当前会话和上一步操作保留。会话可用“结束检查”释放，在时窗结束后旧状态不再有效。弹出的通行提示得在实际操作中关掉，之后才能继续选分支。存在只能用触屏操作进入的区域。

每页声明终端、入口、语言、操作方式、发布批次、首页版本和本页安装版。首页版本和页面版本暂时不同时，能够观察到的仍可能属于旧安装版。新版范围确实存在需由实际界面查证。“导览尚未更新”与终端不再可检查均不能代表活动取消。指引卡的状态 cancelled 表示该版公开宣布取消，open 表示该版给出的可走顺序。每张指引的各路段还受现场通行约束。

## 通行表和发布单

发布任务声明入口及公告适用的带队时段，可有多个通行组与方式。stairs 可用楼梯，step-free 对应需要无台阶的通行组。现场表每条相邻检查点为有向边，开放时间含起始不含结束。对同一方向用当前公告轮可见的最新一组记录，适用人群或开放时间可变。反方向有自己的记录。整个拟发布时间段须能在指引所列顺序通行。允许对原带队时段建议较窄的可发布区间，同时显示出了该区间哪里仍缺通行证据。沿途几点的顺序以实际活动页为依据。

## 志愿者公告

“已送指引”按交接号和服务点列表显示具体旧路线、适用方式、人群及时间。停用某一交接时填写稳定通知号、原交接号、对应服务点和停发起始时间。回条可能晚于“已送”显示。依旧指引的实际服务点各有接收范围，同一条路线发给两个服务点时，通知和已读需逐个核对。用查询通知号可确认处理状态。重新送同号同内容不会产生第二次办理，改内容用不同通知号。演练志愿者在后续轮次陆续确认。

“发布新指引”记录具体活动、通行条件、路线和时间，检查点用英文逗号按顺序填写。接收方是发布任务上的一个服务点。相同交接号仍需保持原单内容。公告台只记录实际发布或通知，不代替展务复核页面、决定是否可走或选择适用时段。

## 运行

依赖版本见 `requirements.txt`。浏览器演练使用 Playwright 配套的 Chromium。

```sh
python3 -m pip install -r requirements.txt
python3 -m playwright install --with-deps chromium
python3 kiosk.py --port 8040
python3 -m unittest discover -s tests -v
```
